# 🚗 Montgomery Fleet Inventory Analysis

## 📌 Project Overview
This project is part of a peer-graded final assignment in a data analysis course. The objective was to clean and analyze a dataset related to the fleet equipment inventory of Montgomery County, using Excel for the Web.

---

## 🧼 Part 1 – Data Cleaning

### ✅ Tasks Completed:
- Converted the original CSV file to `.xlsx` format
- Adjusted column widths for better visibility
- Removed all empty rows using filter functionality
- Identified and deleted duplicate records
- Checked and corrected spelling mistakes
- Removed extra whitespace using Find and Replace
- Reviewed department names and validated against official list
- Skipped Flash Fill step since department names were already in one column

### 📁 Output file:
- `Montgomery_Fleet_Equipment_Inventory_FA_PART_1_END.xlsx`

---

## 📊 Part 2 – Pivot Table Analysis

### ✅ Tasks Completed:
- Formatted the cleaned data as a structured table
- Used AutoSum to calculate:
  - SUM: 2242
  - AVERAGE: 18.22
  - MIN: 1
  - MAX: 704
  - COUNT: 123
- Created 3 Pivot Tables:
  - Pivot Table 1: Sum of Equipment Count by Department
  - Pivot Table 2: Department & Equipment Class breakdown (expanded only for Transportation)
  - Pivot Table 3: Equipment Class & Department breakdown (expanded only for CUV)
- Sorted all pivot tables in descending order by Equipment Count

### 📁 Output file:
- `Montgomery_Fleet_Equipment_Inventory_FA_PART_2_END.xlsx`
